# Laboratório e legado

O diretório `legacy-2026-10-29/` preserva os scripts utilizados durante a investigação. Arquivos executáveis de texto foram arquivados com sufixo `.txt`, mantendo os bytes originais, para não virarem pontos de entrada acidentais.

Esses scripts contêm caminhos, rótulos, COM e identidades específicos da tentativa. O aplicativo final deve migrar as regras para um plano dinâmico e validado. Não usar os arquivos históricos como instalador geral.

Não foram copiados os wheels Python, o VHDX WSL nem as imagens de gigabytes. O inventário externo e a proveniência registram suas localizações quando relevantes. A compilação do bootstrap tem uma receita separada em `build/bootstrap/`.
