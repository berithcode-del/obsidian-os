# Driver FEL

No laboratório foi associado WinUSB ao dispositivo FEL `1F3A:EFE8` usando Zadig 2.9 oficial. Nenhum instalador de driver público foi preparado aqui.

O produto precisa resolver preparação restrita ao dispositivo correto, autoria/assinatura do pacote, elevação e recuperação de cancelamento. Nunca aplicar automaticamente um driver a todos os dispositivos USB ou substituir drivers de outros equipamentos.
